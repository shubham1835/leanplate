# ⚡ Fit Fuel Diet Café — Web PWA

Mobile-first React PWA for Fit Fuel Diet Café.
Built with React 18 + Vite + Redux Toolkit + React Router v6.

---

## 🚀 Quick Start (Mock Mode — no backend needed)

```bash
# 1. Install dependencies
npm install

# 2. Enable mock mode (already set in .env.local)
# VITE_USE_MOCK=true is the default — nothing to change

# 3. Start dev server
npm run dev
# → http://localhost:3000
```

**Login with any valid 10-digit phone number and OTP: `123456`**

## 🧪 Mock Mode

Mock mode lets you run and test the entire app without the Spring Boot backend.

### How it works

```
.env.local
  VITE_USE_MOCK=true
        │
        ▼
src/core/mock/serviceFactory.js   ← single toggle
        │
  ┌─────┴──────┐
  │ USE_MOCK   │
  │  = true    │
  └─────┬──────┘
        │
        ▼
mockServices.js       ← in-memory implementations
mockData.js           ← all realistic test data
```

All slices and hooks import services from `serviceFactory.js` — swapping mock ↔ real is a single env var change.

### Mock credentials

| Field  | Value          |
|--------|----------------|
| Phone  | Any valid 10-digit number (e.g. `9876543210`) |
| OTP    | `123456`       |

### What mock mode covers

| Feature              | Mock behaviour |
|----------------------|---------------|
| OTP Auth             | Any phone + OTP `123456` logs in |
| Full Menu (25 items) | Loaded from `mockData.js` instantly |
| Goal filtering       | Works — items filtered by `goalFit` array |
| Place order (plan)   | Deducts a meal from in-memory sub |
| Place order (Razorpay)| Returns fake Razorpay order ID |
| Active order tracking| Returns `ORD1043` in PREPARING state |
| Order history        | 4 past orders with macros |
| Subscription plans   | All 3 plans, pause/resume works |
| Progress / Weight log| 7-day history, new entries persist in session |
| Rewards & streaks    | 340 pts, 4 milestones |
| Trainer referrals    | Code `TRN-2847`, 5 clients |
| Admin dashboard      | Daily analytics, weekly revenue chart, live orders |

### Visual indicator

A green `MOCK` banner appears at the top of every screen when mock is active.

## 🔌 Switch to Real API

```bash
# .env.local
VITE_USE_MOCK=false
VITE_API_URL=http://localhost:8080/api/v1
```

Start the Spring Boot backend from `fitfuel-backend/`, then restart the dev server.

## 📁 Project Structure

```
src/
├── config/           apiConfig.js (env-aware URL)
├── core/
│   ├── api/          apiClient.js (Axios + interceptors)
│   ├── navigation/   routes.js, AppNavigator, AuthNavigator, MainNavigator, BottomNav
│   ├── services/     Real service implementations (6 files)
│   ├── mock/         mockData.js · mockServices.js · serviceFactory.js · MockBanner.jsx
│   └── store/        store, rootReducer, 6 slices
├── features/         11 features × (screens/ + hooks/ + styles/)
├── shared/           components, theme, constants, utils
├── screens/          ErrorBoundary, SplashScreen
└── i18n/             i18n.js + en.json
```

### Key convention: screens never import services directly

```
Screen  →  Hook  →  Thunk  →  serviceFactory  →  mockService OR realService
```
